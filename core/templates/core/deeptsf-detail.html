DeepTSF

Developed by ICCS
Interface Codeless UI
Tooling MLflow & Dagster
Models 10 built-in

DeepTSF, developed by ICCS, enables the development and deployment of time series forecasts using highly accurate, state-of-the-art AI models. DeepTSF empowers business stakeholders, domain experts, and forecasters from the industry to develop, monitor, and deploy large-scale machine learning and deep learning forecasting experiments without coding. This allows them to effortlessly train and evaluate a wide range of forecasting models with diverse machine learning techniques, deep learning architectures, and hyperparameter configurations.

Main functionalities
1
Codeless Forecasting Pipeline

You can train your Machine Learning models via a user intuitive UI.

2
Experiment tracking and model evaluation

Evaluate your Machine Learning models and visualise Actual vs Forecasted values. It is mainly focused on users with limited modeling expertise and aims to offer them a brief high-level overview of the results.

3
Model Deployment

Deploy your best Machine Learning models in an easy manner.

4
System Monitoring

Monitor the system's current status through a user interface that showcases real-time data pertaining to the overall resources including memory, GPU, and CPU utilization of the deployed infrastructure.

5
Features for advanced users

Ability to further develop, configurate, tweak any parameter using advanced tools (through MLflow & Dagster).

Featured AI models

DeepTSF provides out-of-the-box state-of-the-art forecasting models, including N-BEATS, Transformer, NHiTS, temporal convolutional networks, (block) recurrent neural networks, temporal fusion transformers, LightGBM, ARIMA, random forest, and seasonal naïve.

Train, evaluate, and monitor forecasting experiments through the DeepTSF codeless interface.
