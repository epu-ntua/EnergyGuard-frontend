TiRex

Developed by NXAI
Architecture xLSTM
Parameters 35M
Forecasting Foundation Models

TiRex is a 35 million parameter time series forecasting model built on the xLSTM architecture by NXAI, introduced in the paper TiRex: Zero-Shot Forecasting Across Long and Short Horizons with Enhanced In-Context Learning. It forecasts zero-shot, so it needs no training, no fitting, and no hyperparameter tuning on your data. You upload a history in the single time series format described in the DeepTSF input format guide, and TiRex returns the continuation, drawing on the general temporal patterns it learned while being pretrained on a large corpus of time series.

Main functionalities
1
Zero-Shot Forecasting

Generates forecasts directly from your uploaded history, with no training, fitting, or hyperparameter tuning required.

2
Cross-Domain, Cross-Resolution

Works across domains and sampling rates, without being tied to a specific data source or frequency.

3
Short and Long Horizon Coverage

Covers both short and long forecasting horizons from the same model.

5
Single Time Series per File

For now, each request takes a single time series, uploaded in the DeepTSF input format.

TiRex is available as a REST API on EnergyGuard. Consult the API docs to submit a forecast request.
