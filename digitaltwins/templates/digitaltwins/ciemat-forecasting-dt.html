The Renewable Generation Forecasting Service is a CIEMAT node service, provided by the EnergyPrediction application, that estimates wind and photovoltaic power output at the CEDER-CIEMAT microgrid. It offers three complementary modes: 5-day weather-based forecasting, real-time power calculation from live measurements, and a model comparator that evaluates the multilag wind model against the base models.

Configure a run
Two generation types, three ways to use them

Forecast wind power for the NED100 turbine or photovoltaic power for the Afrisol reference plant. Run a 5-day forecast for a location, calculate instantaneous output from live measurements, or compare the wind models against each other.

How it works

Choose a Mode

5-day forecast, real-time calculation, or model comparator.

Select Generation Type

Choose wind or photovoltaic, and provide location or live measurements.

Run

EnergyPrediction applies its forecasting or ML correction models.

Results

Review KPIs and charts, and export or save the data.

What you'll need to provide

Generation type

Choose whether to forecast wind power output (NED100 turbine model) or photovoltaic power output (Afrisol reference plant).

Location coordinates

Latitude and longitude used to retrieve the Numerical Weather Prediction data (Open-Meteo). Must fall within Spain. Defaults to the CEDER-CIEMAT site in Soria, Spain.

Available modes

5-Day Forecast

Predicts wind or PV output over the next five days for a location, combining Open-Meteo weather forecasts with a machine-learning correction model.

Real-Time Calculation

Calculates instantaneous wind or PV power output from live measurements, at 1-second, 1-minute or 5-minute resolution for wind.

Model Comparator

Evaluates the differences between the wind multilag model (1-second) and the base models (1-minute, 5-minute) for the same measurements.

Compare with a Second Model

A toggle inside 5-Day Forecast that adds a second, independently configured model (any generation type, any location) and runs both over the same 5-day window for a direct side-by-side comparison. Distinct from the Model Comparator, which compares the wind multilag and base models directly.
