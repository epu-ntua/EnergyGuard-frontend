What is in the JSON file?

The scenario file is a single JSON object containing time-series signals (varying over time) and scalar parameters (constant values) used to run the simulation.

Time-series signals

Arrays of values associated with the time vector. All signals must have the same length as timeStamp.

9 variables
Scalar parameters

Single values used across the entire simulation.
