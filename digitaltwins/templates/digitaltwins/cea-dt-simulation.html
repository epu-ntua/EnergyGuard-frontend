The DT Scenario Simulation is a CEA node that runs the SOEC (Solid Oxide Electrolysis Cell) Digital Twin on a scenario you provide, returning the raw time-series output of the simulated test.

Build a scenario
One scenario, a full SOEC simulation

Provide the operating conditions and degradation coefficients that define your test, either by filling in the scenario table below or by uploading a scenario file generated with the AI Scenario Generation node. The Digital Twin runs the SOEC simulation and returns the raw output as an .h5 file, ready to download or open directly in JupyterHub.

How it works

Build

Fill in the scenario table or upload a scenario file.

Run

Launch the SOEC Digital Twin simulation.

Monitor

Track simulation progress in real time.

Results

Download the resulting .h5 output file.

What you'll need to provide

Scenario values

Typed or pasted into the scenario table, or uploaded as a single JSON file of up to 10 MB.

Time-series signals

9 variables — current, voltage, temperature, steam conversion and gas flowrates — each given a value at every time step.

Scalar parameters

4 degradation coefficients, one per stack, applied as constant values across the whole simulation.
