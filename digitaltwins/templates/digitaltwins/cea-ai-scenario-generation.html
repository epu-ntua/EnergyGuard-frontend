A few numbers, a full scenario

No need to hand-craft time-series signals or degradation coefficients. Describe the test at a high level and the AI model produces a scenario file compatible with the SOEC Digital Twin.

How it works

Provide inputs

Set the test duration and hydrogen quantity, and optionally tune scenario-variation settings.

Generate

The AI model builds a complete scenario matching these targets.

Review

Inspect the generated signals and scalar parameters.

Use

Download the file or run it directly in DT Scenario Simulation.

What you'll need to provide

Test duration

How long the simulated test should run for, between 1 and 240 hours.

Hydrogen quantity

The target amount of hydrogen to produce during the test, in kg H₂.

Optional — to vary the scenario

Leave these unset for a default scenario, or tune them to generate a different variant.

Applied current

The nominal current density applied to the electrolysis stack, in Amps.

Steam flowrate

The steam flowrate available at the input of the system, in NL/min.
